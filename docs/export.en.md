# Export

## At a Glance

Export creates files from a documented application for storage or sharing. Depending on the settings, PSMSimple either saves the files on the server or downloads them in the browser. Always check the **Preview** before exporting.

Available actions:

- **Preview** for checking
- **Save** for server-side storage
- **Download** for browser download

## How the Function Works

## What is exported

The export contains the data of the documented application. This includes, among other things:

- farm
- application with date, time, and type of use
- plant protection products with application rate
- crops with BBCH code
- fields and areas

## Use preview

Click **Preview** before saving or downloading. The preview shows the generated data and helps detect mistakes early.

Check especially:

- correct products
- correct application rates
- matching crop and BBCH code
- correct fields
- date and time
- responsible person and applicator

## Save

If **Save** is shown, PSMSimple stores the generated files on the server. This is useful when documentation should be collected centrally.

After saving, PSMSimple shows a confirmation with the generated file names.

## Download

If **Download** is shown, PSMSimple downloads the documentation in the browser. Depending on the system, the download may be a ZIP file or individual files.

The file name usually contains the date and, if possible, the name of the first selected plant protection product.

## History

When saving or downloading, the application is also stored in the history. This allows you to review the application later even if you do not have the export file at hand.

## Common Issues

## Export button is disabled

At least one required value is missing. Check the documentation page and review the message below the buttons.

## Download does not start

Check whether the browser is blocking downloads or whether popup/download protection is active. Then try the download again.

## PDF is not downloaded

In some server configurations, the PDF file may be stored on the server. Check the export behavior setting or ask an administrator.
