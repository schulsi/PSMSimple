# Farm

## Compact

In **Farm**, you maintain the master data of your farm or business. These details are used in documentation entries, exports, and history records. Check them before documenting the first application and update them whenever address or responsibility details change.

Important fields:

- company
- first and last name
- street and house number
- postal code and city
- federal state

## Detailed

## What farm data is used for

Farm data forms the fixed header of many documentation records. When you save or export an application, the current farm details are included in the generated documentation.

For that reason, set up the farm data before documenting the first application.

## Open Farm

Open **Farm** in PSMSimple. You will see the input fields for the master data.

## Enter details

Enter the data exactly as it should appear in the documentation.

Maintain especially:

- **Company**, if the farm uses a company or business name
- **Last name** and **First name** of the responsible person
- **Street + house number**
- **Postal code**
- **City**
- **Federal state**

## Save

After making changes, click **Save**. Only then will the details be used for new documentation entries.

Applications already stored in the history keep the data that was used at the time they were saved.

## Common Issues

## Data does not appear in the export

Check whether the farm data was saved. Then reopen the documentation page or create a new preview.

## Old history entries show previous data

This is expected. History entries reflect the state at the time of the application. New farm data applies to new documentation entries.
