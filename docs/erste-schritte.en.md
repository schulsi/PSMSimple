# Getting Started

This page walks you through the first steps in PSMSimple: signing in, checking master data, and preparing your first documentation entry.

## 1. Open the application

Open PSMSimple in your browser. The address depends on your installation, for example:

- local development: `http://localhost:5001`
- Docker installation: `http://localhost:8080`

If PSMSimple is hosted on a server, ask the responsible person or administrator for the correct address.

## 2. Create an account or sign in

On the first start, the first user can usually be created. This first user receives administrator permissions.

After setup, sign in with your username and password. If registration is no longer available, it has probably already been disabled. In that case, contact an administrator.

## 3. Check farm data

Open the **Farm** section and review the master data. This information is used in documentation entries and exports.

Check especially:

- farm name
- address and contact details
- responsible persons
- additional farm information required for your documentation

## 4. Create application sites

In **Application Sites**, you create fields, areas, or locations where applications take place.

Typical details include:

- site name
- area
- location or coordinates
- optional notes

Clean application site data makes later documentation and analysis easier.

## 5. Maintain crops and BBCH stages

In **Crops**, you manage the crops used in your operation. BBCH stages can be used to document growth stages more precisely.

Create the crops you use regularly. Add BBCH stages if they are relevant for your documentation.

## 6. Add plant protection products

In **Plant Protection Products**, you add products that can later be used in applications.

Before using a product, check:

- product name
- approval or registration details
- active substances, if maintained
- application rate and unit
- notes or restrictions

## 7. Document the first application

Once farm data, application sites, crops, and plant protection products are prepared, you can document an application.

Select the matching master data and add the actual application details, such as date, area, product, application rate, and responsible person.

## 8. Use export and history

After saving, you can export the application and find it later in the **History** section. The history helps you review, trace, and reopen documented applications.

## Next steps

After the basic data is set up, it is useful to review:

- **Settings**, to check personal defaults and system options
- **Inventory**, if you want to manage product stock levels
- **Forecast**, if weather data and spray windows are used
- **Advisory**, if the optional PSM advisory feature has been configured
