# Application Sites and Fields

## Compact

In **Fields**, you create the areas where applications are documented. A field should have at least a name, an area, and ideally a crop assignment. Only fields matching the selected crop will later appear in the documentation workflow.

Important fields:

- name or label
- coordinates or location
- application area
- area and unit
- site
- crop

## Detailed

## What fields are used for

Fields connect an application to a specific area. This makes it clear where a plant protection product was applied.

The crop assignment is especially important because PSMSimple only shows fields that match the selected crop during documentation.

## Create a new field

1. Open **Fields**.
2. Click **+ New Field**.
3. Enter the field data.
4. Click **Save**.

## Maintain field data

Maintain the data as completely as possible:

- **Name / label** for clear identification
- **Coordinates** as latitude and longitude
- **Application area**, such as open field, greenhouse, or storage
- **Geo type**, such as GPS coordinates, polygon, or field name
- **Area**
- **Unit**, such as ha, m2, or ar
- **Site**
- **Crop**

## Use the map

If available, use **Show map** to select coordinates more comfortably. Afterwards, check whether the values were copied into the field form.

## Create a site

If the required site does not exist yet, users with the required permission can create one directly with **+ New Site**.

## Edit or delete a field

In the field list, use **Edit** to change existing fields. Use **Delete** to remove a field.

Only delete fields if they are no longer needed. Old documentation data remains stored in the history.

## Common Issues

## Field does not appear in documentation

Check whether the correct crop is assigned to the field. After selecting a crop in the documentation workflow, only matching fields are shown.

## No permission to create fields

If **+ New Field** is not visible, you probably do not have write permissions. Contact an administrator.

## Area or unit is wrong

Edit the field and correct the area and unit. New documentation entries will then use the updated values.
