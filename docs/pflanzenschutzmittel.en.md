# Plant Protection Products

## At a Glance

In **Plant Protection Products**, you maintain products that are later used in applications. If possible, select a product from the search so the approval number and active substances are filled automatically. Add the application rate unit, bee hazard classification, and inventory details.

Important fields:

- name
- approval number
- active substances
- application rate unit
- bee hazard classification
- inventory unit
- minimum and warning stock level

## How the Function Works

## What plant protection products are used for

Plant protection products are selected during application documentation and recorded with an application rate. Master data helps identify products clearly and avoids entering recurring information again and again.

## Create a new product

1. Open **Plant Protection Products**.
2. Click **+ New Product**.
3. Enter the name.
4. If possible, select a result from the search.
5. Add the remaining details.
6. Click **Save**.

## Use search

While entering the name, PSMSimple shows matching results. When you select a result, the approval number and active substances can be filled automatically.

If no result appears, check the spelling or create the product manually.

## Application rate unit

The unit is later shown next to the entered application rate in the documentation.

Typical units are:

- kg/ha
- l/ha
- g/ha
- ml/ha

## Bee hazard classification

Select the matching classification:

- B1
- B2
- B3
- B4

The classification serves as an important note in the master data. Always verify legally relevant information against the current approval and product information.

## Inventory details

If you use inventory management, also maintain:

- inventory unit
- minimum stock level
- warning stock level

These details support stock warnings and later inventory management.

## Edit or delete a product

Use **Edit** to change existing products. Use **Delete** to remove a product from the master data list.

Only delete products if they are no longer needed. Historical applications keep the stored data.

## Common Issues

## Product does not appear in documentation

Check whether the product was saved. Then reopen the documentation page or reload the application.

## Approval number or active substances cannot be edited

These fields may be filled automatically and protected through search selection. Select the matching search result or create the product with the available details.

## Wrong unit in documentation

Edit the product and correct the application rate unit. New applications will then use the updated unit.
