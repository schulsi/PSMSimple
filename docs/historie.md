# Historie

## Kompakt

Die **Historie** zeigt gespeicherte Anwendungen und Auswertungen zur Verwendung von Pflanzenschutzmitteln und Feldern. Sie können nach Zeitraum filtern, Details öffnen und bei entsprechender Berechtigung Einträge löschen.

Bereiche:

- Applikationen
- PSM-Verwendung
- Felder-Verwendung

## Ausführlich

## Wofür die Historie verwendet wird

Die Historie hilft Ihnen, dokumentierte Anwendungen nachzuvollziehen. Sie zeigt nicht nur einzelne Applikationen, sondern auch Übersichten darüber, welche Mittel und Felder in einem Zeitraum verwendet wurden.

## Applikationen anzeigen

Im Bereich **Applikationen** sehen Sie die gespeicherten Anwendungen.

Die Liste zeigt unter anderem:

- Datum und Uhrzeit
- Art der Verwendung
- Felder
- Pflanzenschutzmittel
- Kulturen

Mit **Details** öffnen Sie die vollständigen Daten einer Anwendung.

## Details prüfen

Die Detailansicht zeigt die gespeicherten Daten in mehreren Abschnitten:

- Anwendung
- Betrieb
- Kulturen und BBCH
- Felder
- Pflanzenschutzmittel

Diese Ansicht eignet sich gut, um eine frühere Anwendung fachlich oder organisatorisch zu prüfen.

## Zeitraum filtern

Über **Von** und **Bis** grenzen Sie den Zeitraum ein. Zusätzlich gibt es Schnellauswahlen wie:

- Dieser Monat
- Letzter Monat
- Dieses Jahr
- Letztes Jahr

Mit **Zurücksetzen** wird der Filter wieder auf den Standardzeitraum gesetzt.

## PSM-Verwendung auswerten

Im Bereich **PSM-Verwendung** sehen Sie, wie oft Pflanzenschutzmittel im gewählten Zeitraum verwendet wurden.

Die Tabelle zeigt:

- Pflanzenschutzmittel
- Anzahl der Verwendungen
- Gesamtmenge
- letzte Verwendung

Wenn Diagramme verfügbar sind, wird zusätzlich eine grafische Übersicht angezeigt.

## Felder-Verwendung auswerten

Im Bereich **Felder-Verwendung** sehen Sie, welche Felder im gewählten Zeitraum verwendet wurden.

Die Tabelle zeigt:

- Feld
- Anzahl der Verwendungen
- letzte Verwendung
- Details

Über die Detailanzeige können Sie die Anwendungen zu einem Feld öffnen.

## Einträge löschen

Benutzer mit Schreibrechten können Historieneinträge löschen. Verwenden Sie diese Funktion vorsichtig, da gelöschte Einträge nicht mehr in den Auswertungen erscheinen.

## Häufige Probleme

## Keine Einträge sichtbar

Prüfen Sie den Zeitraumfilter. Möglicherweise liegen die Anwendungen außerhalb des gewählten Zeitraums.

## Details laden nicht

Laden Sie die Seite neu und versuchen Sie es erneut. Wenn das Problem bleibt, prüfen Sie die Verbindung zum Server oder wenden Sie sich an einen Administrator.

## Eintrag lässt sich nicht löschen

Wahrscheinlich fehlen Ihnen die erforderlichen Schreibrechte. Wenden Sie sich an einen Administrator.
