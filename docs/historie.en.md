# History

## At a Glance

**History** shows saved applications and usage summaries for plant protection products and fields. You can filter by date range, open details, and delete entries if you have the required permission.

Sections:

- applications
- product usage
- field usage

## How the Function Works

## What history is used for

History helps you trace documented applications. It shows not only individual applications, but also summaries of which products and fields were used during a selected period.

## View applications

In **Applications**, you see saved applications.

The list shows, among other things:

- date and time
- type of use
- fields
- plant protection products
- crops

Use **Details** to open the full data of an application.

## Check details

The detail view shows the stored data in several sections:

- application
- farm
- crops and BBCH
- fields
- plant protection products

This view is useful for reviewing a previous application technically or organizationally.

## Filter by date range

Use **From** and **To** to limit the date range. There are also quick selections such as:

- this month
- last month
- this year
- last year

Use **Reset** to restore the default date range.

## Analyze product usage

In **Product Usage**, you see how often plant protection products were used during the selected period.

The table shows:

- plant protection product
- number of uses
- total quantity
- last use

If charts are available, a graphical overview is shown as well.

## Analyze field usage

In **Field Usage**, you see which fields were used during the selected period.

The table shows:

- field
- number of uses
- last use
- details

Through the detail display, you can open the applications for a field.

## Delete entries

Users with write permissions can delete history entries. Use this carefully, because deleted entries no longer appear in summaries.

## Common Issues

## No entries are visible

Check the date filter. The applications may be outside the selected date range.

## Details do not load

Reload the page and try again. If the problem remains, check the server connection or contact an administrator.

## Entry cannot be deleted

You probably do not have the required write permission. Contact an administrator.
