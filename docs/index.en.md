# PSMSimple User Guide

PSMSimple helps you document plant protection applications digitally. The application manages master data such as farm details, application sites, crops, and plant protection products, and uses them to create traceable application records.

## What is PSMSimple for?

With PSMSimple you can:

- maintain farm master data
- manage application sites, fields, and areas
- maintain crops and BBCH stages
- record and reuse plant protection products
- document applications and export them as JSON
- review previous applications in the history
- manage inventory levels and stock movements
- create operational notes, notifications, and reports
- use weather data and spray window forecasts
- optionally use PSM advisory features based on configured AI services

## Typical workflow

1. Create or review the farm profile.
2. Set up application sites and crops.
3. Add plant protection products to the master data list.
4. Document an application.
5. Generate and download an export if needed.
6. Review entries later in the history.

## Who is this documentation for?

This documentation is intended for users who work with PSMSimple in daily operations. It explains the most important workflows from a user perspective and does not require technical knowledge.
